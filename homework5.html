Numerical analysis / integration / probability

Numerical integration and the normal distribution.

This assignment investigates two numerical problems. The first compares approximations inspired by Riemann and Lebesgue integration. The second develops numerical methods for evaluating the cumulative distribution function of the standard normal distribution.

Exercise 1 / Numerical integration

Riemann and Lebesgue integration

1.1 Theoretical background

Integration can be understood through two different ways of approximating the area under a function. The Riemann approach partitions the domain into small subintervals. The Lebesgue approach instead partitions the range of function values and considers the measure of the sets of points whose function values belong to each range interval.

Riemann approximation

Consider a bounded function f(x) defined on [a,b]. Divide the domain into N intervals of equal width:

Δx = (b − a) / N

Using the midpoint of each interval, the integral is approximated by:

∫ab f(x) dx ≈ Δx Σ f(xi*)

where xi* is the midpoint of the i-th subinterval. As the number of intervals increases, the approximation converges to the integral for suitable Riemann-integrable functions.

Lebesgue-inspired approximation

Instead of dividing the x-axis, divide the range of the function into small intervals of width Δy. For a non-negative function, the integral can be approximated by considering the measure of the preimages of the range thresholds:

∫ f(x) dx ≈ Δy Σ μ({x : f(x) ≥ yk})

Here, μ denotes the measure (length) of the set of domain points whose function values are at least yk. This is a simple-function approximation: each horizontal range level contributes its height multiplied by the measure of its preimage.

For functions that can take negative values, the implementation shifts the range by its minimum value before applying the approximation.

Important: The numerical Lebesgue-inspired method below estimates the preimage measures using a finite set of domain samples. It is therefore a practical approximation to the Lebesgue construction, not an exact symbolic computation of measurable sets.

1.4 Pathological examples

Dirichlet function

f(x) = 1 if x is rational
f(x) = 0 if x is irrational

Every interval contains both rational and irrational numbers. Therefore, in every subinterval, the supremum of the function is 1 and the infimum is 0. The upper and lower Riemann sums cannot converge to the same value. Consequently, the Dirichlet function is not Riemann-integrable.

However, the rational numbers form a countable set and therefore have Lebesgue measure zero. The irrational numbers have measure one on [0,1]. Since the function is zero on the irrationals, its Lebesgue integral is:

∫01 f(x) dx = 0
Numerical limitation: Every ordinary finite decimal grid point is rational. A direct grid-based Riemann experiment therefore evaluates this function as 1 at every sampled point and returns 1. The Lebesgue result of 0 follows from the measure-theoretic argument above; it cannot be recovered by simply counting ordinary finite grid samples.

Thomae's function

f(x) = 1/q if x = p/q in lowest terms
f(x) = 0 if x is irrational

Thomae's function is discontinuous at every rational number and continuous at every irrational number. Despite having infinitely many discontinuities, it is bounded and Riemann-integrable on [0,1]. Its integral is zero.

The reason is that for any positive threshold ε, only finitely many rational numbers in [0,1] can have a denominator small enough to make the function value at least ε. The measure of these points is zero. As ε becomes smaller, the function values outside these exceptional points become arbitrarily small.

∫01 f(x) dx = 0

In a numerical experiment, the sampled values approach zero on average as the resolution increases, although convergence can be relatively slow.

1.5 Comparison and interpretation

For continuous functions such as sin(x), x² and |x − 0.5|, both approaches should converge to the same integral as the domain and range resolutions increase.

The Riemann method uses a fixed number of domain evaluations. It is generally straightforward and efficient, especially for smooth functions. Its accuracy depends on the partition and the choice of sample points.

The Lebesgue-inspired method first estimates the range of the function and then counts how much of the domain belongs above each range threshold. Its accuracy depends on both the number of domain samples and the number of range bins.

For a finite numerical approximation, the Lebesgue-inspired approach can require more operations because each sampled value contributes to the range partition. Increasing the number of range bins can improve the approximation but also increases computational work.

Conclusion for Exercise 1: For bounded Riemann-integrable functions, the Riemann and Lebesgue integrals are equal. The two numerical procedures approximate the same mathematical quantity but use different partitions. The Dirichlet function demonstrates that Lebesgue integration can handle functions that are not Riemann-integrable. Thomae's function demonstrates that infinitely many discontinuities do not necessarily prevent Riemann integrability.

Exercise 2 / Probability and numerical methods

Numerical computation of the normal CDF

2.1 Definition of the standard normal CDF

The standard normal distribution is a continuous probability distribution with mean zero and variance one. Its probability density function (PDF) is:

φ(x) = (1 / √(2π)) e−x²/2

The cumulative distribution function (CDF) gives the probability that a standard normal random variable is less than or equal to a given value x:

Φ(x) = P(Z ≤ x)
Φ(x) = (1 / √(2π)) ∫−∞x e−t²/2 dt

The CDF is important in statistics because it allows us to calculate probabilities, percentiles and critical values associated with the normal distribution.

2.2 Why is the normal CDF not an elementary function?

The integrand of the normal distribution contains the exponential term e−x²/2. Although this function is elementary, its antiderivative cannot be expressed using a finite combination of elementary functions such as polynomials, exponentials, logarithms and trigonometric functions.

This result is related to Liouville's theorem on elementary integration. In differential algebra, Liouville's theorem characterises the possible forms of antiderivatives that can be expressed using elementary functions. Applying the result to the Gaussian exponential shows that e−x², and therefore also e−x²/2, has no elementary antiderivative.

This does not mean that the integral does not exist or cannot be evaluated. It means that its antiderivative requires a special function or a numerical approximation.

The error function

The error function, written as erf(x), is a special function defined by:

erf(x) = (2 / √π) ∫0x e−t² dt

Using the substitution t = u / √2, the standard normal CDF can be expressed exactly in terms of the error function:

Φ(x) = 1/2 [1 + erf(x / √2)]

This is an exact analytical representation, but erf is itself a special function rather than an elementary one. Numerical computation is still required in practical applications because the error function generally needs to be evaluated using algorithms, approximations or precomputed numerical tables.

2.3 Numerical methods implemented

Method A — Simpson's rule

Simpson's rule approximates a definite integral by fitting quadratic polynomials over pairs of subintervals. For an even number N of subintervals, the approximation is:

∫ab f(x) dx ≈ (h/3) [f(x₀) + f(xN)
+ 4Σ f(xodd) + 2Σ f(xeven)]

To compute the normal CDF, we use the symmetry of the standard normal distribution:

Φ(x) = 1/2 + ∫0x φ(t) dt,   x ≥ 0

For negative x, symmetry gives Φ(−x) = 1 − Φ(x). This avoids numerically integrating over an infinite interval.

Method B — Power series for erf

The error function can also be represented by the power series:

erf(z) = (2/√π) Σk=0∞ [ (−1)k z2k+1 / (k!(2k+1)) ]

The series converges for every finite real value of z. In the implementation, terms are added until the next contribution is sufficiently small or a maximum number of iterations is reached.

2.6 Accuracy and computational efficiency

Simpson's rule approximates the integral directly. For a sufficiently smooth function, its global truncation error is proportional to h⁴, where h is the integration step size. Increasing the number of subdivisions therefore generally improves accuracy, although the computational cost also increases.

The error-function series uses a different strategy. It approximates the special function through a sequence of terms. For moderate values of z, it can provide highly accurate results with relatively few terms. For large absolute values, however, alternating terms can become large before cancelling, which may cause numerical cancellation and loss of precision.

The two approaches have different computational characteristics:

  • Simpson's rule: accuracy depends on the number of subdivisions; it evaluates the density function repeatedly.
  • Erf series: accuracy depends on the number of terms; it is convenient for moderate arguments but may suffer from cancellation for larger arguments.
  • Reference tables: provide fast values at predefined points, but are limited by their tabulated precision and available z-values.
Practical consideration: Production numerical libraries often use specialised rational approximations, continued fractions or carefully designed polynomial approximations. These methods can be more efficient and numerically stable over a wider range than a basic series or fixed-step integration.

2.7 Conclusion

The standard normal CDF is an essential function in probability and statistics. Although it is defined by an integral of the normal density, it has no elementary antiderivative. Liouville's theorem explains why an elementary closed-form expression is not possible.

The error function provides an exact analytical representation of the CDF, while numerical methods make its values practically computable. In this assignment, Simpson's rule and the power series of erf provide two independent approaches to the same mathematical quantity.

Comparing their results with trusted normal-table values demonstrates how numerical integration and series approximations can achieve accurate results, while also illustrating the trade-off between precision, computational effort and numerical stability.
